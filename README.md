# Conversor de Unidades Multitarea

## Descripción
Proyecto colaborativo en Java desarrollado dentro del marco de la materia de Control de Versiones. Esta aplicación permite realizar conversiones de diferentes magnitudes físicas (masa y longitud) mediante una interfaz modular, organizada y fácil de utilizar. El desarrollo se gestionó mediante flujos de trabajo colaborativos en Git y GitHub.

## Objetivo
Desarrollar e integrar mejoras funcionales sobre una base de código compartida, aplicando de manera rigurosa flujos de trabajo basados en ramas (`feature branches`), revisiones de código entre pares (*peer review*), resolución de conflictos e integración continua mediante Pull Requests.

## Funcionalidades
- **Funcionalidades originales:**
    - Menú interactivo en consola para navegación de opciones.
    - Gestión básica de entrada y salida de datos.
- **Aporte del Estudiante 1 (Renato Villacís):**
    - Implementación de la clase `ConversorMasa.java` para conversiones entre Kilogramos, Gramos, Libras y Onzas.
- **Aporte del Estudiante 2 (Anderson Freire):**
    - Implementación del conversor de unidades de longitud (Metros, Centímetros, Kilómetros y Milímetros) e integración de validación de datos de entrada.

## Tecnologías Utilizadas
- **Lenguaje de programación:** Java (JDK 17)
- **Control de versiones:** Git
- **Plataforma colaborativa:** GitHub
- **Editor / IDE:** IntelliJ IDEA / Visual Studio Code
